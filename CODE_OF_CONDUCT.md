# Code de conduite

Centrol est un projet ouvert à tous. Dans les issues, discussions et demandes de fusion :

- **sois respectueux** : critique les idées, pas les personnes ;
- **sois constructif** : explique le problème, propose si possible une piste ;
- **sois patient** : le projet est maintenu sur du temps libre ;
- **pas de harcèlement**, de propos discriminatoires ou d'attaques personnelles.

Les messages qui ne respectent pas ces règles peuvent être modifiés ou supprimés, et leurs auteurs exclus du dépôt. Pour signaler un problème de comportement : ouvre une issue « Conduite » ou contacte le mainteneur en privé.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
